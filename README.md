# VS Code Portfolio - React

A VS Code-themed portfolio website built with React.

## Features

- **4 Color Themes**: Dark+, Light+, Ocean Blue, Midnight Purple
- **Interactive Terminal**: Type commands like `help`, `open about`, `download cv`
- **Command Palette**: Press `Ctrl+P` to quick search files
- **Tips/Features Panel**: Click the 💡 lightbulb icon to see all website features
- **Fully Responsive**: Mobile navigation drawer

## Activity Bar Icons

```
📁 Explorer     - File tree navigation
🔍 Search       - Filter and search files
🔀 Source Control - Git commit history
💡 Features     - Website tips and features guide
⚙️ Settings     - Cycle through 4 themes
```

## Quick Start

```bash
npm install
npm start
```

## Themes

Click the **settings gear** icon to cycle through:

1. **Dark+** - Classic VS Code dark
2. **Light+** - Clean light theme
3. **Ocean Blue** - Modern blue aesthetic
4. **Midnight Purple** - Rich purple tones

## Terminal Commands

- `help` - Show available commands
- `open [section]` - Navigate to about/projects/videos/contact
- `download cv` - Download resume PDF
- `clear` - Clear terminal
- `whoami` - Show profile info

## Keyboard Shortcuts

- `Ctrl+P` - Open command palette
- `Escape` - Close modals
